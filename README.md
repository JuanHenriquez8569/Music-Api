# 🎵 Mini Enciclopedia Musical en Python

Aplicación desarrollada en Python para explorar información de artistas, portadas, álbumes y letras de canciones utilizando tres APIs gratuitas y públicas.

## 🚀 APIs Utilizadas
1. **[MusicBrainz API](https://musicbrainz.org/doc/MusicBrainz_API):** Para buscar artistas, metadatos y discografías (No requiere API Key, solo un User-Agent).
2. **[The AudioDB](https://www.theaudiodb.com/):** Para obtener imágenes, avatares y recursos visuales.
3. **[Lyrics.ovh](https://lyricsovh.docs.apiary.io/):** Para consultar las letras de las canciones en tiempo real (Totalmente abierta, sin claves).

2. Abre el proyecto en tu entorno de desarrollo (como PyCharm).
3. Asegúrate de activar tu entorno virtual (`venv`).
